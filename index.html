Quarterly cash, or year-end distribution? Mode A keeps the base flat and ships profits every quarter. Mode B lets position size ratchet up at each scaling milestone within the year, then distributes the full annual profit at year-end. Both modes obey the cap. Both reset to base on a defined cadence. They differ only in distribution rhythm.
